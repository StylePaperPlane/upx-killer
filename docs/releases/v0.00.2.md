# UPX Killer v0.00.2

This release stabilizes the ELF32 PIE vertical slice and the release process.

## Changes

- Adds production support for little-endian x86 ELF32 dynamic PIE and static
  PIE alongside the existing ELF32 `ET_EXEC` and ELF64 executable paths.
- Preserves dynamic metadata, `REL`, PLT, interpreter semantics, load bias, and
  observable program behavior in the validated ELF32 PIE fixtures.
- Hardens Linux ptrace handling for timeout, early crash, multithreading,
  `SIGSEGV`, `SIGILL`, and software/hardware execution-breakpoint cleanup.
- Adds a single stabilization regression entry covering Release build, native
  tests, CMake/CTest, project/Filter audit, four UPX 5.2.0 ELF32 PIE variants,
  direct unpackaged launch, bilingual resources, and WinUI automation.

## Distribution

Download `upx-killer-v0.00.2-windows-x64.zip`, extract the complete folder, and
double-click `upx-killer\upx_killer.exe` or run `run.ps1`. ELF unpacking requires
a WSL2 distribution selected on the Configuration page. The application remains
an unpackaged, self-contained WinUI 3 folder deployment; no MSIX/Appx install is
required.

Only English and Simplified Chinese runtime language resources are included.
