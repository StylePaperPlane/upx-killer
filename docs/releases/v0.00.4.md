# UPX Killer v0.00.4

## Changes

- Fixes PE import recovery for packed samples whose restored PE64 IAT starts at a four-byte aligned address. The scanner validates runtime export pointers in both alignment lanes and rejects overlapping candidates.
- Limits exclusion of the packed file's own imports to source import descriptors, thunks, and names that can be verified from the source bytes. It continues to reject uncertain import plans.
- Captures fixed-base PE images at their preferred base when the packed file retains shell relocation metadata despite setting `RELOCS_STRIPPED`. Target crashes during capture retain their native exception code instead of being reported as missing OEP evidence.
- Detects a suitable installed WSL distribution for ELF Host builds and acceptance scripts instead of assuming a distribution name.
- Adds a Configuration page update check that compares the installed version with the latest stable GitHub Release. It only reports availability; it does not install updates.
- Corrects `run.ps1` so it launches the application both with and without command-line arguments and returns the application's exit code.

## Distribution

Download `upx-killer-v0.00.4-windows-x64.zip` and verify it with the accompanying SHA-256 file. Extract the complete folder, then double-click `upx-killer\upx_killer.exe` or run `run.ps1`.

This remains an unpackaged, self-contained WinUI 3 folder deployment. ELF unpacking requires a supported WSL2 distribution. Only English and Simplified Chinese runtime language resources are included.
